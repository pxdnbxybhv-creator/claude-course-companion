# Contributing

Contributions are welcome, especially:

- improvements to prompt clarity
- new responsible learning workflows
- examples for different university subjects
- accessibility improvements
- translations

Please avoid contributions that:

- encourage academic dishonesty
- present AI output as guaranteed correct
- add unnecessary technical complexity
- claim unsupported performance or learning outcomes

## How to contribute

1. Open an issue or a pull request describing the change.
2. Keep the project Markdown-first. It does not need build tooling, dependencies, or automation.
3. If you add an example, use your own summary or clearly illustrative content. Do not include copyrighted textbook or lecture material.
4. Keep the tone practical and modest, consistent with the rest of the repository.
