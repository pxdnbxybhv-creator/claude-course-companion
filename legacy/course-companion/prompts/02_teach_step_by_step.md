# 02 — Learn Step by Step

## Usage

Use this after selecting one topic from the knowledge map.

Send this prompt in the same conversation where you built the knowledge map, and state which section you want to study (for example, "Let's start with CPU virtualization").

## Prompt

```text
Teach me the selected topic step by step.

For each major concept:

1. Explain the intuition first in simple language.
2. Give the formal definition or technical explanation.
3. Show how it connects to concepts I already learned.
4. Give one concrete example.
5. Explain one common misunderstanding or mistake.
6. Ask me one short check-for-understanding question.

Do not overwhelm me with every detail at once.

If my answer shows that I misunderstood something, explain the misunderstanding before continuing.

When useful, distinguish clearly between:

- intuition
- formal definition
- example
- common mistake

Do not move too quickly to the next major concept if the prerequisite concept is still unclear.

At the end of the section:

- summarize the key ideas
- list 3–5 things I should be able to explain without looking at my notes
```

## Tips

- Actually answer the check-for-understanding questions instead of skipping them. The value of this step comes from finding out what you do not yet understand.
- If an explanation is unclear, ask Claude to explain it a different way rather than moving on.
- Keep your notes open and compare Claude's explanations with the course material, especially for definitions and notation that your course uses in a specific way.
