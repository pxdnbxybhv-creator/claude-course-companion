1.3　语法错误与语义错误

a. 语法错误（C 语言）：int x = 5 缺分号；if x > 0 { } 条件缺括号；for (i = 0; i < n; i++ 括号不配对。语义错误：int x = "hello"; 类型不匹配；使用未声明的变量 y = 3;；给函数传错参数个数；3 = x;（左边不是左值——结构合法，意思不合法）。

b. 用 gcc 试试一个同时含两类错误的文件。你会发现：如果语法错误严重到分析程序无法继续，gcc 往往只报语法错误；而在能恢复的情况下，两类错误混杂出现。混杂说明它在同一遍里做语法分析和语义分析（分析程序一边建树一边调用语义检查），而不是先完整地做完一遍语法分析。

1.7　用 T 型图造 Pascal 编译器

已有：① Pascal → C 的翻译器，用 C 写（T 型图：Pascal / C / C）；② C 编译器，运行在机器 H 上（C / H / H）。

  1. 用 C 编译器编译翻译器（情形 2）：Pascal/C/C 落在 C/H/H 上，得到 Pascal / C / H——一个能在 H 上运行的 Pascal → C 翻译器。
  2. 把它和 C 编译器串联（情形 1）：Pascal/C/H 接 C/H/H，得到 Pascal / H / H——一个在 H 上运行、生成 H 代码的 Pascal 编译器。

检验：每一步都对照 1.6 节的"三条口诀"，尤其是第 1 步落下去的字母（C）必须等于下方横杠左端的字母（C）。

第 2 章的作业

2.1　写正则表达式

设 letter = [a-z]，digit = [0-9]。

  1. 以 a 开头且以 a 结尾：别忘了长度为 1 的串 a 本身！a | a letter* a。
  2. 以 a 开头或以 a 结尾：a letter* | letter* a。两部分重叠（既以 a 开头又以 a 结尾的串被两边都匹配）没有关系——选择是并集。
  3. 不含前导零的数字串：单独的 0 是合法的，其他串必须以 1–9 开头：0 | [1-9] digit*。
  4. 偶数：最后一位是偶数字：digit* [02468]。（如果也要求无前导零，就和 (c) 合并：0 | [1-9] digit* [02468] | [2468]。）

2.2　用文字描述语言

  1. (a|b)* a (a|b|ε)：{a, b} 上倒数第一位或倒数第二位是 a 的所有串。检验：ab（倒数第二位 a）✓，ba ✓，bb ✗，abb ✗。
  2. (A|B|…|Z)(a|b|…|z)*：一个大写字母后跟任意多个小写字母——首字母大写的单词，如 Hello、X。

2.4　为什么不规定结合性

因为选择和连接都满足结合律：L((a|b)|c) = ({a}∪{b})∪{c} = {a}∪({b}∪{c}) = L(a|(b|c))；L((ab)c) = L(a(bc)) = {abc}。既然无论怎样加括号得到的语言都一样，就不需要规定。（对比减法：(8−3)−2 ≠ 8−(3−2)，所以算术必须规定减法左结合。）

2.5　证明 L(r**) = L(r*)

两个方向的包含。⊇：L(r*) ⊆ L((r*)*) 显然——任何集合 X 都满足 X ⊆ X*（取"重复一次"）。⊆：L(r**) 的成员是若干个 L(r*) 成员的连接；每个 L(r*) 成员本身是若干个 L(r) 成员的连接；连接起来仍然是若干个 L(r) 成员的连接，因此属于 L(r*)。直觉：“任意多次地做‘任意多次重复’”还是“任意多次重复”。

2.8　为 2.1 画 DFA

用 2.3.2 节"给状态起含义"的方法：

  1. 状态：起始、已读 a 开头且当前以 a 结尾（接受）、已读 a 开头但当前以非 a 结尾。起始读 a 到接受态；接受态读 a 留在原地、读其他字母到第三态；第三态读 a 回接受态、读其他留在原地。
  2. 状态：起始、以 a 开头（接受，之后读什么都留在这里）、不以 a 开头且当前以 a 结尾（接受）、不以 a 开头且当前不以 a 结尾。四个状态。
  3. 状态：起始、读到单独的 0（接受，再读任何数字都出错）、读到 1–9 开头（接受，读任意数字留在原地）。
  4. 状态：起始、当前末位是偶数（接受）、当前末位是奇数。每读一个数字，按它的奇偶决定去哪个状态。

四个都存在 DFA——正如 2.3.5 节的补充所说，凡是能用正则表达式写出来的，就一定有 DFA。

自测清单

Self-Check

合上讲义，对照下面的清单逐条自问。能用自己的话回答（而不是背出课件原句）才算掌握。打不上勾的条目，回到对应小节再读一遍。

第 0 章

  • 我能解释 ε 和空格的区别，以及 {ε} 和 { } 的区别。
  • 给定两个小语言 A、B，我能写出 A ∪ B、AB、A* 的成员。
  • 我能画出一个日常设备（闸机、电梯门）的状态机，并说明"有限"指的是什么。

第 1 章

  • 我能说出编译器的定义，并解释"等价"为什么是硬性要求。

  • 给定一条赋值语句，我能画出它经过六个阶段时的每一种中间表示（记号、分析树、语法树、注释树、优化后的树、目标代码）。
  • 我能解释常数合并、以及"目标机器的性质"是如何影响代码生成的（乘 2 那条指令）。
  • 我能说出符号表和常数表的区别，以及为什么符号表用哈希表。
  • 我能解释前端/后端划分为什么带来 M + N 而不是 M × N。
  • 我能画出 T 型图的两种拼接，并完成作业 1.7。
  • 我能用自己的话讲清楚自举的三步，以及为什么最后一步是必要的。
  • 我能读懂 TINY 的阶乘程序，并解释 TM 的"寄存器 + 偏移量"寻址。

第 2 章

  • 我能区分记号、词素、属性，并写出记号记录的结构体。
  • 我能说出正则表达式的三种基本表达式、三种运算及其优先级，并用集合运算解释每一种。

  • 我能解释为什么 anban 不能用正则表达式描述。

  • 我能写出 DFA 的五元组定义，并用文字解释 L(M)。
  • 给定正则表达式，我能画出 DFA；给定 DFA，我能说出它接受的语言。
  • 我能解释 [other] 的含义，以及为什么定界符不能被消耗。
