# 云端工作区

这是我在 Claude Code 云端环境中处理日常任务的个人工作区：写论文、生成 PDF、整理资料等。

## 目录结构

```text
papers/   论文与文稿的源文件（Markdown / LaTeX / docx）
pdf/      导出的 PDF 成品
output/   其他生成的文件（表格、幻灯片、图表等）
assets/   图片、参考资料等素材
```

## 使用方式

1. 把任务需要的素材放进对应目录（或直接在对话中描述需求）。
2. 让 Claude 在云端完成写作、排版、转换等工作。
3. 成品会输出到 `pdf/` 或 `output/`，并提交到 git 以便随时取回。

## 说明

- 云端容器是临时的，任何需要保留的成果都应提交并推送到仓库。
- 本仓库之前是 "Claude Course Companion" 提示词项目，旧内容仍可在 git 历史中找到。
