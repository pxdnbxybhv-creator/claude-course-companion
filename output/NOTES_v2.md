# IMG_1297 第二版：生成式重绘到“真 4K”

第一版（纯超分）见 `NOTES.md`，成品 `IMG_1297_4K_AI.png` 原样保留，方便两版对照。

## 结论

- 成品：`output/IMG_1297_4K_v2.png`。3840×2160，RGB 8-bit，带 `sRGB` 块，没有透明通道，无损 PNG，7.8 MB（7,802,341 字节），SHA-256 `2142c9a2079d1d26c249fe0ebf6cf272144ce6cfd32cee4b98575d0422af9989`。
- 做法：以第一版的 AI 放大结果为起点，用 Stable Diffusion 1.5 的动漫模型加 ControlNet Tile，直接在 4K 分辨率上分块重绘。这样 AI 是真的“画”出了 4K 级别的细节（岩壁的块面和裂缝、发丝、衣褶、云雾、暗部的笔触），而不只是把原有的边缘变锐。
- 人物按“不偏离人设原画”处理：两位角色的脸在全局重绘时完全锁住，之后单独放大，用低强度精修；而且大于约 9 px 的结构都取自原图。精修后两张脸在结构层面和原图几乎一样：模糊 σ=3 后的 PSNR 为 48.8 dB 和 47.6 dB，平均色偏不到 0.1 个色阶。服装配色、红领带、黑手套、咲弥右眼上的白花、光环和飘带，以及那把长剑的外形，也都保持原样。

## 角色与设定核对

- 左边是咲弥（Saya），右边是洞烛（Insight，天赋第八究明者，也就是主线 Act II 里的 Lacrymira），都来自 lowiro 的音游 Arcaea。
- 查到的设定要点：咲弥是及肩的水绿色头发，**右眼被一朵白花覆盖**；洞烛穿军装风格的服饰，形象更成熟。人设相关的维基和图站（萌娘百科、Arcaea 中文维基、Fandom、Miraheze、TV Tropes、Danbooru）在这个环境里都打不开（403、402 或反爬拦截），所以其余细节一律以这张原图为准：凡是和人设有关的地方都以锁定或低强度为主，不让 AI 自由发挥。
- 左边角色手里拿的是**长剑**。第一版说明里我误写成了“长枪”，已经在 `NOTES.md`、区域 1 的对比图标题和文件名里一并改正。这一版给剑所在区域的提示词是“long sword, straight silver blade”（长剑，笔直的银色剑身），剑的外形也锁定在原图上（强度 0.32，ControlNet Tile 约束结构）。

## 最终处理流程

1. **起点**：第一版里 Real-CUGAN 2x conservative 的 4K 结果。它是那一轮最干净的纯 AI 结果，没有混入基准图带来的锯齿和压缩块。
2. **全局重绘**（`scripts_v2/run_global_v3.py`、`scripts_v2/sdtile.py`）：
   - 整张图分成 18 块，每块 896×896，相邻块至少重叠 256 px。每块**各自独立**跑一次完整的 img2img：VAE 编码一次、去噪、VAE 解码一次。所有块共用同一张全局噪声图，最后在像素空间用余弦权重混合。
   - 模型：Counterfeit-V3.0 加 ControlNet Tile（权重 0.85），CFG 6.0，DPM++ 2M Karras，24 步。
   - 每块的提示词按块里有什么内容自动拼接（`scripts_v2/regions_v2.py`）：
     - 咲弥：水绿色短发、白花、白色荷叶边裙、深绿披风、飘带，以及“长剑，笔直的银色剑身”。
     - 洞烛：银色长发、白外套、深蓝裙、红领带、黑手套。
     - 背景：灰白岩壁、柔和的厚涂笔触、低饱和。
     - 提示词里不写 girl，避免在背景里长出人脸。
   - 逐像素强度图（思路来自 Differential Diffusion）：背景 0.46，人物 0.30，剑 0.32，手 0.25，脸 0（完全锁定，像素级保留）。
   - UNet 和 ControlNet 用 bf16（借助 AMX 指令），VAE 用 fp32。
3. **颜色校正**：用 StableSR 的小波颜色校正，约 32 px 以上的低频（整体颜色和明暗）取原图的 Lanczos 放大，更细的高频取重绘结果。
4. **脸部精修**（`scripts_v2/detail_pass.py`、`run_faces.py`）：两张脸各取 224×224，放大到 768 后重绘（强度 0.35，ControlNet 1.0，CFG 6，种子 77）。然后在 768 尺度上再做一次小波，把约 9 px（按 4K 计）以上的结构锁回原图，缩小后用羽化椭圆贴回。所以眼睛的形状和位置、咲弥右眼上那朵花的轮廓都来自原图，AI 只补更细的线条和质感。我也试了强度 0.45，AI 开始改动五官（洞烛的眼睛形状和脸上的阴影都变了），所以用 0.35。
5. **色度保护**（`scripts_v2/v2_post.py`）：亮度细节全部用重绘结果；色度（Cb/Cr）和 Real-CUGAN 的差距限制在 ±6 个色阶以内，防止出现原画色板里没有的颜色。实际被限制的像素占 2.36%。
6. **保存**：RGB PNG，带 `sRGB` 块。保存后重新读回校验：3840×2160，colortype 2（RGB，没有 alpha），文件里只有 `IHDR`、`sRGB`、`IDAT`、`IEND` 四种块，像素逐一相同；四边没有黑边或压暗的边。

## 走过的弯路（为什么最后是这个方法）

对比图 `compare_v2/process-attempts-*` 放了三次整图重绘的对比。

1. **尝试 1**（MultiDiffusion 整图重绘，背景强度 0.5，46 分钟）：提示词里写了“虹彩光、金色涡纹、冰晶、青色光粒”，结果岩壁和暗部出现大量饱和的青色、金黄色碎片，100% 下像撒了彩纸屑。改成中性提示词，负面提示词加上“彩色斑点、闪粉、平涂色块”后，这个问题消失了。
2. **尝试 2**（MultiDiffusion，新提示词，背景强度 0.46，37 分钟）：碎片没有了，但 100% 下岩壁是一块块平涂色块，而单块测试时是自然的厚涂。逐项排查：
   - 不是随机种子造成的：同一块换 3 个种子，结果都正常。
   - 不是块间平均造成的：改成顺序分块、不做平均，一样发平。
   - 真正的原因是**把不同 VAE 编码块的 latent 拼在了一起**。SD 的 VAE 会在少数位置放很大的数值（实测最大 17.7，而 latent 的标准差只有 0.85），用来携带整块的全局信息。不同块的这些位置拼在一起就对不上：VAE 编码加解码往返的 PSNR 从 41.5 dB 掉到 34.5 dB，UNet 也被带偏。
3. **像素空间顺序分块**（小范围测试，每块自己编码、解码）：质感恢复正常，但块交界处有一条竖向接缝，梯度突增到中位数的 2.2 倍。原因是新块的输入在交界处本身就是断开的：一边是上一块画好的纹理，一边是还没处理的原图。
4. **最终方法**（34 分钟）：所有块都从同一张连续的原图出发，共用噪声，用 896 px 的大块加 256 px 的余弦混合。按列统计高频能量，混合带中心和两侧的比值是 0.94–1.53，落在非混合区域的正常波动范围内（0.55–1.19），没有“接缝”或“变软的条带”。

## 检查结果

| 指标（定义同 `NOTES.md`） | v1 | v2 |
|---|---|---|
| 一致性 PSNR（缩回原尺寸后和原图比） | 37.9 dB | 31.5 dB |
| 平均色偏 R / G / B（色阶） | −0.02 / −0.06 / +0.17 | +0.01 / 0.00 / −0.02 |
| 局部色偏最大（σ=8 模糊后） | 1.4 | 5.4 |
| 细节：脸1 / 脸2 / 岩壁 / 暗部（纯 Lanczos 为 1） | 1.80 / 1.79 / 1.41 / 0.65 | 1.89 / 1.84 / 1.56 / 0.77 |
| 纹理相关：岩壁 / 暗部 | 0.958 / 0.762 | 0.448 / 0.180 |
| 两张脸的结构 PSNR（σ=3 模糊，对比 Real-CUGAN） | — | 洞烛 48.8 dB，咲弥 47.6 dB |

- v2 的一致性 PSNR 和纹理相关明显更低，这是生成式重绘本来就会有的：岩壁和暗部的纹理是 AI 按原图结构**重新画**的，不再是原图像素的放大。人物和脸是锁住的，所以脸部的结构指标很高。
- 目视检查（`compare_v2/`）：
  - 两张脸的五官、比例和表情都没变。
  - 咲弥右眼的白花形状不变。
  - 长剑仍是笔直的长刃，剑尖和护手的位置不变。
  - 洞烛的手套、蝴蝶结、裙摆细节都保留，发丝更细更多。
  - 咲弥的披风、裙摆上的小花、光环和飘带的设计都不变。
  - 暗部提亮 5 倍后没有色带。
  - 分块之间没有接缝，没有彩色碎片。

## 自由创作的部分（和原图不同的地方）

- 岩壁：原图是柔和的厚涂，v2 画出了更明确的岩石块面、裂缝和刀刮般的笔触。
- 暗部（右上）：原图细碎的噪点和颗粒，被重画成平滑的厚涂块面，金色涡纹保留但更干净。
- 云雾、冰晶、地面碎石：增加了层次和边缘细节。
- 发丝、衣褶、裙摆荷叶边：线条更细、更多。

## 不足

- 岩壁和暗部的笔触已经不是原作者的笔触，而是 AI 依照原图结构重新画的。想要“原作笔触的放大”，看 v1；想要“看起来像 4K 原画”，看 v2。
- 原图 (2500, 650) 附近一块偏黄的亮斑，在 v2 里颜色变淡、变灰了一些。
- 咲弥左上方发饰上的白花不在脸部锁定范围内，花瓣形状比原图柔和了一点，但仍然是白花。
- 为了不偏离人设，眼睛内部没有让 AI 新增结构，脸只补了细线和质感，所以放到 300% 看，眼睛仍不如真正的 4K 原画精细。
- 人设只能以这张图为准：官方人设资料站在这个环境里都打不开，没法逐项和官方立绘对照。
- 受 CPU 限制，只能用 SD1.5 这一代模型；有 GPU 的话，用 SDXL 或 Flux 这类更新的模型重绘，细节会更好。

## 复现

脚本在 `output/scripts_v2/`，还依赖 `output/scripts/` 里的 `common.py`、`finalize.py`、`make_compare.py`（运行时两个目录都要在 `PYTHONPATH` 里）；路径同样写死在 `/tmp/upscale` 下。

```bash
python run_global_v3.py                                   # 全局重绘（需要第一版的 Real-CUGAN 4K 结果）
python run_faces.py                                       # 两张脸的精修
python assemble_v2.py output/IMG_1297_4K_v2.png 6         # 合成 + 色度保护（±6 色阶）+ 校验
python make_v2_compare.py                                 # 对比图
```
